# D-02: Mobile Shell

Status: Decided
Decision date: 2026-08-02
Revised: 2026-08-03

Mobile uses the desktop information architecture adapted to a bottom task sheet. The
sheet is the mobile form of the right control pane and remains the single owner of
Photos/People, scoped search, identity state, Sharing, Settings, and filters. Fotos
does not add a persistent top header on mobile; the photo surface keeps the full
viewport height and exposes the task sheet through its normal collapsed handle.
