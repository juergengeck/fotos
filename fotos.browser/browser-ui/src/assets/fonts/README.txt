The Light, Regular and SemiBold WOFF2 files are subsetted with fontTools,
retaining all OpenType features (including slashed-zero alternates).
Unicode ranges: U+0000-052F,U+1E00-1EFF,U+2000-206F,U+20A0-20CF,U+2190-22FF.
These cover Latin, Greek, Cyrillic, punctuation, currency and common symbols.
Other scripts use the browser's monospace fallback.
